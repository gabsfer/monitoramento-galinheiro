# Monitoramento de Galinheiro

Projeto desenvolvido durante meus estudos de Java, com o objetivo de praticar os fundamentos da Programação Orientada a Objetos.

## Sobre o projeto

A aplicação permite registrar informações de um galinheiro, como nome, quantidade de galinhas e produção de ovos por galinha. Com esses dados, o sistema calcula a produção diária e mensal de ovos.

## Funcionalidades

- Cadastro das informações do galinheiro.
- Cálculo da produção diária de ovos.
- Cálculo da produção mensal, considerando um período fixo de 30 dias.
- Exibição das informações cadastradas.

## Conceitos aplicados

- Programação Orientada a Objetos (POO).
- Abstração.
- Encapsulamento.
- Classes, atributos, construtores e métodos.

## Tecnologias

- Java.
